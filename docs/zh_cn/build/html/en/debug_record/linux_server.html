Unable to git clone, error details: fatal: unable to access ‘https://github.com/wnlen/clash-for-linux.git/’: gnutls_handshake() failed: Error in the pull function. (Developer cannot git clone, cannot perform development on the server)¶

Proxy not installed, git clone failed; Installed proxy, failed as before (Installation method as follows: ubuntu server (no GUI) install clash, configure proxy, use clash-for-linux, process shows successful, but still cannot connect to the internet)

Subscription link is fine¶

  • Using clash-for-windows on windows, using this subscription link, connection successful, can connect to the internet

  • The subscription link website shows a device connection successful

Port 7890 is not in use¶

  • http_proxy is 127.0.0.1:7890, https_proxy is 127.0.0.1:7890, no_proxy is 127.0.0.1,localhost

Machine does not have a firewall¶

Current situation¶

  • ping 127.0.0.1 successful

  • www.baidu.com

    • ping/wget/curl successful

  • www.github.com

    • ping successful

    • wget failed

      • Error message: –2025-01-18 12:53:35– http://www.github.com/ Connecting to 127.0.0.1:7890… connected. Proxy request sent, awaiting response… 502 Bad Gateway 2025-01-18 12:53:40 ERROR 502: Bad Gateway

    • curl failed, no print information

  • ssh -T git@github.com successful

    • Hi Alwaysssssss! You’ve successfully authenticated, but GitHub does not provide shell access.

  • www.google.com

    • PING www.google.com (31.13.88.169) 56(84) bytes of data. Card dead

    • wget failed

    • curl failed, no print information

Solution, based on ssh git clone (git clone –recursive git@github.com:nndeploy/nndeploy.git) (refer to realtyxxx’s configuration)¶

  • Add the following code in $HOME/.ssh/config in the root directory

Host github.com
    Hostname ssh.github.com
    Port 443
    User git

  • Add the following code in $HOME/.gitconfig in the root directory

[user]
  # 修改为用户邮箱
	email = user@gmail.com 
  # 修改为开发者用户名
	name = user 
[http]
	# version = HTTP/1.1
	sslVerify = true
	# sslBackend = openssl
[https]
	sslVerify = true
[url "ssh://git@github.com/"]
	insteadOf = https://github.com/
[credential]
	helper = manager-core
