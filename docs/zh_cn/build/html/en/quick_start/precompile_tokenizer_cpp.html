Installing the Rust environment on Ubuntu mainly involves the following steps:

Preparation before installation¶

  1. Update the system software package list to ensure the system is up to date:

    sudo apt update
sudo apt upgrade

  2. Install necessary compilation tools and dependency libraries:

    sudo apt install curl build-essential gcc make

Install Rust¶

  1. Use the official script installation: Execute the following command to download and run the Rust installation script.

    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

    运行该命令后，安装脚本会提示你进行一些选择，通常选择默认选项1即可完成安装。

  2. 使用镜像源安装：如果官方安装速度较慢，可以使用国内镜像源来加速安装。

    export RUSTUP_DIST_SERVER=https://mirrors.ustc.edu.cn/rust-static
export RUSTUP_UPDATE_ROOT=https://mirrors.ustc.edu.cn/rust-static/rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Configure environment variables¶

After the installation is complete, you need to add Rust’s related paths to the environment variables so that the system can find Rust’s tools. You can use the following commands:

source $HOME/.cargo/env

Verify the installation¶

You can check the versions of the Rust compiler (rustc) and package manager (cargo) to verify whether the installation was successful:

rustc --version
cargo --version

If version information is displayed, it indicates that the installation was successful.
