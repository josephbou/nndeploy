Translation Script¶

This document lists the available translation script options in the nndeploy project, helping developers configure and build the program according to their requirements.

1. 编译宏编辑规则¶

For most translation options, only ON/OFF is used.

However, for external dependencies, there are three methods to enable and link to external third-party libraries.

  • Method one: Path, the header file and library’s root directory path, which must be modified to

    • Header file: path/include

    • Library: path/lib

    • Windows dll: path/bin

    • Corresponding libraries: ONNXRuntime, OpenVINO, TNN, MNN, Windows already translated OpenCV libraries

  • Method two: Turn ON, if you have installed the library, and can find the library through find_package, you can use this method.

    • Corresponding libraries: CUDA, CUDNN, TensorRT, OpenCV under Linux platform

  • Method three: Source code ON, use source code translation for this library, for libraries under the third_party directory, you can use this method.

    • Corresponding libraries: tokenizer-cpp, rapidjson, gflags, ONNX

2.基础构建选项（建议采用默认值）¶

宏 默认值 描述
ENABLE_NNDEPLOY_BUILD_SHARED ON 构建为共享库而非静态库
ENABLE_NNDEPLOY_SYMBOL_HIDE OFF 隐藏库中的符号以减小二进制大小
ENABLE_NNDEPLOY_COVERAGE OFF 启用代码覆盖率分析
ENABLE_NNDEPLOY_CXX11_ABI OFF 使用C++11 ABI
ENABLE_NNDEPLOY_CXX14_ABI OFF 使用C++14 ABI
ENABLE_NNDEPLOY_CXX17_ABI ON 使用C++17 ABI（推荐）
ENABLE_NNDEPLOY_CXX20_ABI OFF 使用C++20 ABI
ENABLE_NNDEPLOY_OPENMP OFF 启用OpenMP进行并行计算
ENABLE_NNDEPLOY_ADDRESS_SANTIZER OFF 启用地址消毒器进行内存错误检测
ENABLE_NNDEPLOY_DOCS OFF 构建文档
ENABLE_NNDEPLOY_TIME_PROFILER ON 启用时间分析器进行性能分析
ENABLE_NNDEPLOY_RAPIDJSON ON 启用RapidJSON进行JSON解析，基于path/to/nndeploy/third_party/rapidjson源码编译

8. 编译选项举例说明¶

  • nndeploy connects to the inference backend ONNXRuntime through the path. set(ENABLE_NNDEPLOY_INFERENCE_ONNXRUNTIME “path/to/onnxruntime”), if you want to enable and connect to other inference backends (OpenVINO, MNN, TNN …), you can do the same processing

  • nndeploy connects to the inference backend TensorRT through the find_package method. set(ENABLE_NNDEPLOY_INFERENCE_TENSORRT ON), for other libraries that can be found through find_package, you can do the same processing

  • nndeploy connects to the third-party library tokenizer-cpp through the source code. set(ENABLE_NNDEPLOY_PLUGIN_TOKENIZER_CPP ON), for other libraries that can be translated through source code, you can do the same processing (all libraries in third_party are currently translated through source code)

  • Translation algorithm plugin. First, set the model type set(ENABLE_NNDEPLOY_PLUGIN_XXX ON), then set the specific model set(ENABLE_NNDEPLOY_PLUGIN_XXX_YYY ON)
